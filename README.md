Інструкція з запуску FastAPI-проєкту

    Вимоги до середовища
  Перед запуском переконайтеся, що на комп’ютері встановлено:

✔ Python 3.10+

✔ pip (менеджер пакетів для Python)

✔ Git (Клонуємо репо)

        Клонування репозиторію
Копіюємо посилання на гіт і клонуємо репозиторій в нашій IDE, або вручну завантажуємо та розпаковуємо ZIP-архів з проектом

    Створення та активація віртуального середовища(Встановлення залежностей)
Файл requirements.txt містить усі необхідні бібліотеки. Встановлюємо їх:

pip install -r requirements.txt


      Налаштування змінних середовища (якщо є .env)
Якщо у проєкті використовується файл .env, його потрібно створити та заповнити.

Приклад .env:

SECRET_KEY=your_secret_key
DATABASE_URL=sqlite:///./database.db


      Запуск FastAPI-сервера
Виконуємо команду:

uvicorn main:app --reload

    Якщо все працює, у терміналі з’явиться повідомлення:
Application startup complete.
  Перевірка документації API: Swagger UI: http://127.0.0.1:8000/docs

Uvicorn running on http://127.0.0.1:8000

        Запуск бази даних PostgreSQL(Встановити PostgreSQL, DataGrip (JetBrains)
потрібно створити та налаштувати сервер, я використовував postgresql в DataGrip, створюємо бд(Add data source(PostgreSQL)) - тестуємо конект 

      Перегляд таблиць у DataGrip
Відкриваємо Database Explorer(ліва панель)
  Переходимо до public - tables
    Після запуску серверу мають з'явитися дві таблиці items та users
